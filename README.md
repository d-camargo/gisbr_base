# gisbr_base

Base pré-processada de dados para o plugin QGIS [gisbr](https://github.com/d-camargo/gisbr), começando pela rede viária do OpenStreetMap por Região Metropolitana, publicada como um arquivo por RM nas Releases.

## Estado

v0.1.0: Release de dados `osm-20260929` com as 84 RMs (rede veicular). Contrato: `manifest.json` (schema 1).
URL estável: `https://github.com/d-camargo/gisbr_base/releases/latest/download/<asset>`.
